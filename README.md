Medical Insurance Cost Forecaster

Project Overview

This is a Machine Learning project that predicts estimated medical insurance costs based on personal information.

Dataset

Medical Cost Personal Dataset (Kaggle)

Features Used

* Age
* Sex
* BMI
* Number of Children
* Smoking Status
* Region

Machine Learning Models

1. Linear Regression
2. Random Forest Regression

Project Workflow

* Data Collection
* Data Cleaning
* Exploratory Data Analysis (EDA)
* Data Visualization
* Data Preprocessing
* Model Training
* Model Evaluation
* Cost Prediction

Technologies Used

* Python
* Google Colab
* Pandas
* Matplotlib
* Seaborn
* Scikit-learn

Project Purpose

To learn and apply Machine Learning techniques for predicting medical insurance costs.

Disclaimer

This project is for educational purposes only. Predictions are estimates and are not actual insurance quotes.
